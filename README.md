# Multi-Agent Research System

An AI-powered research application built with Streamlit that uses multiple agents and web research tools to gather information and generate research results.

## Features

* Multi-agent research workflow
* Web search using Tavily
* Web scraping using BeautifulSoup
* AI-generated research results
* Interactive Streamlit interface

## Tech Stack

* Python
* Streamlit
* Multi-agent framework
* Tavily API
* BeautifulSoup
* LLM API

## How to Run Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure your API keys securely.
5. Run the application using `streamlit run app.py`.
